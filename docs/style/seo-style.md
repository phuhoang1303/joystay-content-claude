# SEO writing style (Vietnamese)

Derived on 2026-11-09 from references the owner chose. Learn structure and voice only; never copy sentences.
- https://vinwonders.com/vi/wonderpedia/news/an-gi-o-sai-gon/
- https://pasgo.vn/blog/tiramisu-by-vincenzo-hanh-trinh-gin-giu-van-sang-tao-huong-vi-y-5805
- https://pasgo.vn/blog/ho-chi-minh

| Item | Rule |
| --- | --- |
| Formats | Listicle "Top N + món/địa điểm + khu vực"; single-venue review with a story; "ăn gì / đi đâu" guide; "X là gì" explainer |
| Title | Keyword + number + area, max 60 characters |
| Meta description | 140-160 characters |
| Intro | Two short paragraphs: one evocative line about the topic, then what the reader will get |
| Structure | Table of contents with anchors; numbered H2s, each = dish/venue name + a question variant ("sáng ăn gì", "trời mưa ăn gì"); do not repeat the exact main keyword in every H2 |
| Each item | 2-4 sentences on taste, space, story; then an info block: address · reference price · opening hours · distance from Joystay Quận 3 (all with sources; volatile ones flagged) |
| Voice | Third person ("du khách", "thực khách") mixed with "bạn"; brand speaks as "Joystay" |
| Sentences | 15-25 words, some short ones for emphasis; concrete details over generic adjectives |
| Images | One per item, caption with real credit (never "Ảnh: Sưu tầm"); descriptive alt text, no stuffing |
| Internal links | 3-5: rooms, booking, related posts |
| Ending | 2-3 sentence recap + soft CTA: staying near these places -> Joystay Quận 3 |
| FAQ | 3-5 questions + FAQ schema (references lack it: advantage) |
| Length | Listicle 1,500-2,500 words; single review 800-1,200 words |
| Avoid | Keyword stuffing, meta over 160 chars, uncredited images, ads crowding content, venue facts without sources |
